# 2DsimulationID

The M-24 Cell — an interactive simulation of a U-shaped manual harness-assembly line, built for
WSU Innovation Design Studio 2 (Molex "Invisible Assembly Line" case, Appendix A).

Open `index.html` directly in a browser, or view the live deployed version at
**https://2dsimulationid.vercel.app** — auto-deploys on every push to `main`.

8 stations, 6 operators + quality tech + line lead + trainer + supervisor + ME, two shifts, 5 case
defect categories, a rework bench, a live event feed, and a data-vs-reality toggle showing what the
current shop-floor process would and wouldn't have caught.
